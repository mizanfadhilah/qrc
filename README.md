Program tersebut digunakan untuk membuat QR Code (Quick Response Code) dari sebuah link atau teks yang dimasukkan oleh pengguna.

Cara kerja program:
1. Mengimpor library untuk membuat QR Code.
2. Meminta pengguna memasukkan link atau teks.
3. Mengatur ukuran dan tingkat keamanan QR Code.
4. Memasukkan data ke dalam QR Code.
5. Mengubah QR Code menjadi gambar.
6. Menyimpan gambar dengan nama qrcode_hasil.png.
7. Menampilkan gambar QR Code.
8. Memberikan pesan bahwa QR Code berhasil dibuat.
